# بياع الحلويين — Ledger

نسخة قابلة للنشر من تطبيق دفتر الموردين، مبنية بـ React + Vite، متصلة بقاعدة بيانات **Supabase** حقيقية بدل تخزين Claude. جاهزة تتفتح كتطبيق (PWA) على شاشة الموبايل الرئيسية بدون أي حاجة لحساب Claude.

## إيه اللي اتغيّر عن نسخة الآرتيفاكت؟

- كل عمليات القراءة/الكتابة بقت بتروح لقاعدة بيانات Supabase (Postgres) بدل `window.storage`.
- كلمات المرور بقت متشفّرة (salted SHA-256) بدل نص عادي — انظر ملاحظة الأمان تحت.
- الجلسة (تسجيل الدخول) بقت متخزنة في `localStorage` الحقيقي للمتصفح، فبتفضل شغالة مهما عدّلت في الكود بعدين.
- مضاف دعم PWA كامل (manifest + service worker) عشان تقدر تعمل "Add to Home Screen" ويظهر كأيقونة تطبيق عادية.

## 1. تجهيز قاعدة البيانات (Supabase)

1. اعمل حساب مجاني على [supabase.com](https://supabase.com) وأنشئ مشروع جديد.
2. من لوحة تحكم المشروع، روح لـ **SQL Editor** والصق محتوى ملف `supabase/schema.sql` كامل واضغط **Run**. ده هينشئ كل الجداول المطلوبة.
3. من **Settings -> API**، هتلاقي:
   - **Project URL**
   - **anon public key**

## 2. إعداد المشروع محليًا

```bash
npm install
cp .env.example .env
```

افتح `.env` واملأ:

```
VITE_SUPABASE_URL=https://your-project-ref.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-public-key
```

بعدين شغّل:

```bash
npm run dev
```

هيفتحلك رابط محلي (عادة `http://localhost:5173`) — أول حساب تعمله بيبقى **مسؤول (admin)** تلقائيًا.

## 3. النشر (Deployment)

أسهل طريقة: [Vercel](https://vercel.com) أو [Netlify](https://netlify.com) (باقات مجانية كافية):

1. ارفع المجلد ده على GitHub repo.
2. من Vercel/Netlify: **Import Project** واختر الـ repo.
3. أضف نفس متغيرات البيئة (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`) في إعدادات المشروع هناك.
4. اضغط Deploy — هتاخد رابط حقيقي زي `https://sweets-vendor.vercel.app`.

## 4. تثبيت التطبيق على الموبايل (بدون حساب Claude)

بعد النشر:

1. افتح رابط الموقع من **Safari** (آيفون) أو **Chrome** (أندرويد).
2. من قائمة المشاركة: **"إضافة إلى الشاشة الرئيسية" / "Add to Home Screen"**.
3. هيظهر أيقونة عادية على شاشة الموبايل، وهيفتح بملء الشاشة زي أي تطبيق تاني — من غير أي علاقة بـ Claude خالص.

## ⚠️ ملاحظات أمان مهمة قبل الاستخدام الفعلي

هذا المشروع جاهز للتشغيل والتجربة، لكن فيه نقطتين لازم تتعالجوا في Claude Code قبل ما تحطه في بيئة عمل حقيقية بأموال حقيقية:

1. **الحماية على مستوى قاعدة البيانات (Row Level Security):** حاليًا أي حد معاه رابط المشروع والـ anon key يقدر يقرا ويكتب في كل الجداول. لازم تفعّل RLS وتربطها بنظام مصادقة حقيقي (الخطوة #2).
2. **نظام تسجيل الدخول:** التشفير الحالي (`src/lib/crypto.js`) بديل عملي سريع، لكن الأفضل الانتقال لـ **Supabase Auth** (`supabase.auth.signUp` / `signInWithPassword`) اللي بيدير التشفير والجلسات بشكل صحيح من جهة السيرفر.

## هيكل المشروع

```
src/
  App.jsx            كل واجهات التطبيق (لوحة التحكم، الموردون، المصاريف، الخزينة، التقارير، المستخدمون)
  lib/
    supabaseClient.js  إعداد اتصال Supabase
    db.js              كل عمليات القراءة/الكتابة على قاعدة البيانات
    crypto.js           تشفير كلمات المرور
  index.css            الأنماط العامة + Tailwind
supabase/
  schema.sql          تعريف الجداول
public/
  logo.png, icon-192.png, icon-512.png   شعار "بياع الحلويين"
```
