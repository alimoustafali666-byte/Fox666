# بياع الحلويين — تطبيق موبايل

نفس البرنامج بالظبط (العملاء، الخزينة، التقارير، المستخدمون)، لكن جاهز يتحول لأيقونة حقيقية على شاشة موبايلك. البيانات بتتخزن في المتصفح على جهازك نفسه — مفيش حسابات، مفيش قاعدة بيانات، مفيش تعقيد.

## الخطوات (من كمبيوتر، لمرة واحدة بس)

```bash
npm install
npm run build
```

هيطلعلك مجلد اسمه `dist`.

## النشر

اسحب مجلد `dist` على [app.netlify.com/drop](https://app.netlify.com/drop) — هياخد ثواني ومن غير أي حساب.

## التثبيت على الموبايل

1. افتح الرابط اللي طلع من Netlify، من **Safari** (آيفون) أو **Chrome** (أندرويد).
2. من قائمة المشاركة: **"إضافة إلى الشاشة الرئيسية"**.
3. هيظهر أيقونة عادية على شاشتك.

**من هنا وطالع:** كل مرة تفتح فيها الأيقونة من نفس الموبايل، بياناتك هتكون موجودة — مفيش حساب Claude، ومفيش إنترنت مطلوب بعد أول تحميل.

## نصيحة

استخدم زرار "تصدير نسخة احتياطية" (في صفحة المستخدمون) بين فترة والتانية — البيانات محفوظة على الجهاز ده بس، فلو غيّرت موبايل يومًا محتاج تنقلها يدويًا بالنسخة الاحتياطية.
