# UAE AI Office — Frontend

Next.js (App Router) + React + TypeScript. See `/docs/uae-ai-office/ARCHITECTURE.md`
and `/docs/uae-ai-office/PHASE_1_DESIGN.md` at the repo root for the full design.

## Local setup

```bash
npm install
cp .env.example .env.local
npm run dev
```

## Status

Phase 1, Step 1 (repository scaffold). Only a placeholder home page exists.
Login, dashboard, projects, and documents pages are added in a later step
once the backend endpoints they depend on exist.
